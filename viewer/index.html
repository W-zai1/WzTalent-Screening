系统按姓名 / 学历 / 工作经历 / 所在地 / 出生年份做多信号比对， 本次得分落在"不确定"区间，因此没有自动合并。 请对照下面的差异自行判断。

记录真实进展

这一步决定这套评分有没有价值：只有把真实面试结果回填回来， "高分是否真的更有戏"才能被检验。不回填，评分就永远只是猜测。

导入 HR 的真实决定

把「这一批简历里，谁被推去面试、谁被淘汰」贴进来，系统就能算出 它排的前 N 名里有几个和你的决定一致。
直接从 Excel 复制粘贴即可（支持逗号或制表符分隔），第一行是表头， 需要包含姓名和决定两列；可再加一列备注。 决定列请用「推进 / 淘汰 / 待定」。

记录决定

决定必须由人来做，并且留下理由 —— 这是可申诉性的最低要求。 系统只提供证据，不替你做决定。

添加标定条目

把你已经人工定过级的候选人加进标定集。系统随后会对比 "人给的等级"与"模型给的等级"的一致率——这是检验评分口径是否靠谱的唯一办法。 只列出当前岗位已有评分的候选人。

新建标定集
